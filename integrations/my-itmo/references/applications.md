# Заявки my.itmo.ru (из личного кабинета)

> Обновляй по мере обнаружения URL и slug'ов в SPA.

## Раздел «Заявки и очереди»

Путь в UI: **Заявки и очереди → Заявки**

### API

- Каталог: `GET /api/requests/all`
- Мои заявки: `GET /api/requests/my`
- Шаблон заявки: `GET /api/requests/{id}`

### Учёба

| ID | Заявка | Назначение |
|---|---|---|
| **124** | **Переводы и восстановления** (категория) | Родительская категория |
| **7266** | Персональная анкета | Обязательный шаг; **доступна сейчас** |
| — | Восстановление после отчисления | **Появится 3–20 августа 2026** (сезонно) |
| Заказ комплекта документов после отчисления | Справки для восстановления / архив |
| Справка об обучении (академическая справка) | Подтверждение периода обучения |
| Справка с указанием данных по всем приказам (архивная) | История приказов |
| Выписка из приказа | Конкретный приказ (отчисление и т.д.) |
| Копия аттестата/диплома | Заказ копий |

### Прочее

| Заявка | Назначение |
|---|---|
| Заказ документов | Общий заказ справок |
| Справка о стипендии и других доходах | Финансовые справки |

## Алгоритм восстановления через my.itmo.ru

1. **Персональная анкета** — создать/обновить
2. **Переводы и восстановления** → «Восстановление в число обучающихся после отчисления»
3. Указать: платное, ОП, курс (3 и/или 2)
4. Дождаться согласования → принести документы в Студофис
5. Следить за уведомлениями в **Мои заявки**

## Навигация для агента

После логина (`ensure_logged_in`):

1. Открыть `https://my.itmo.ru/requests` или **`https://my.itmo.ru/requests?category=124`** (фильтр «Переводы и восстановления»)
2. `snapshot -i` — найти ссылку «Заявки и очереди» или «Заявки»
3. Кликнуть → снова `snapshot -i`
4. Найти нужную заявку по тексту (semantic: `find text "Переводы и восстановления" click`)

> Прямые URL вида `/requests/124` не работают (404). Каталог заявок — через `/api/requests/all`.

## Уведомления

Решения комиссии, даты собеседований и аттестаций приходят в **Мои заявки** → уведомления к конкретной заявке.
