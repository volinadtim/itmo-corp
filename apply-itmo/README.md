## Ключевые даты (лето 2026)

| Событие | Срок |
|---|---|
| Подача заявки в my.itmo.ru | **3–20 августа** (до 19:00) |
| Документы в Студофис | **до 24 августа** |
| Результаты комиссии | **начало сентября** |
| Начало учебного года | ~1 сентября |

## Важно для твоего случая

- Отчисление за **неуспеваемость** = **неуважительная причина** → только **платное** восстановление
- Можно восстановиться на **тот же курс (3)** или **на курс ниже (2)** — указать в заявке
- Несданные предметы (ВМ, ТПВ, физкультура) закрываются **после** восстановления через академическую разницу / ППА / комиссии
- Попыток подачи **не ограничено** в течение 5 лет с даты отчисления
