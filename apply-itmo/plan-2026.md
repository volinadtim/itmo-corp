## План B

| Сценарий | Действие |
|---|---|
| Отказ комиссии | Подать на **январско-февральскую** комиссию |
| Слишком большая академ. разница на 3 курсе | Подать на **2 курс** |
| ОП закрыта | Подать на **другую ОП** (до 5 заявлений) |
| Не хватает денег | Образовательный кредит; рассмотреть восстановление на **2 курс** (отложить часть предметов) |

## Критический путь

```
Доступ my.itmo.ru → Заявка (3–20 авг) → Документы (до 24 авг)
    → Английский → Собеседование → Решение (нач. сент)
    → Договор → Оплата (~330k) → Приказ → Учёба
```

**Блокеры:** нет доступа к my.itmo.ru, нет денег/кредита, не закрыты предметы в срок ППА.
