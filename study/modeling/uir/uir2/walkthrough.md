# Шаг 2. Почему процесс марковский

- Поток простейший. Заявка выбирает прибор случайно и независимо, поэтому поток к
  каждому прибору тоже простейший (разрежение пуассоновского потока).
- Обслуживание экспоненциальное с μ = 0,1, кроме П2 СИСТЕМЫ_2.
- Эрланг-2 со средним 10 с раскладывается на две последовательные экспоненциальные фазы по 5 с
  (интенсивность 2μ = 0,2). Если в состоянии хранить номер фазы, процесс остаётся марковским.

**Почему Эрланг в П2, а не в П1.** В приборе без накопителя закон обслуживания
не влияет на стационарные вероятности (инвариантность систем с отказами). Проверено:
с Эрлангом в П1 модель имеет 15 состояний, а загрузка П1 та же, 0,8182.

# Шаг 5. Уравнения и вероятности

По графу: p_j · (сумма выходящих интенсивностей) = Σ p_i · (входящая интенсивность).
Пример для E0 СИСТЕМЫ_1: (λ1 + λ2 + λ3)·p0 = μ·p1 + μ·p2 + μ·p10. Полный список в
приложение А отчёта. Решено методом Гаусса в дробях, то есть точно.

Проверка СИСТЕМЫ_1: p(n₁,n₂,n₃) = p₁(n₁)·p₂(n₂)·p₃(n₃), где p₁, p₃ по M/M/1/0,
p₂ по M/M/1/3 по формулам Алиева. Совпадает точно, например p0 = (2/11)·p₂(0)·(5/8) = 0,0277.

Проверка П2 СИСТЕМЫ_2: распределение M/E₂/1/3 другим методом, через вложенную цепь
в моменты ухода. P(n₂ = 0) = 8192/170483 = 0,0481 = p0 + p9.

# Шаг 8. Сравнение и выбор

- **Критерий (д)**: l = 1,0345 у СИСТЕМЫ_1 против 1,8937 у СИСТЕМЫ_2 → **СИСТЕМА_1**,
  в 1,83 раза меньше.
- Почему: в СИСТЕМЕ_1 «остаток» потока (25 %) делится между П2 с накопителем (15 %)
  и П3 без него (10 %). В СИСТЕМЕ_2 весь остаток идёт на П2, у которого y₂ = 1,5 > 1:
  прибор перегружен, очередь длиннее.
- При варьировании λ от 0,05 до 1,2 СИСТЕМА_1 лучше по критерию **везде** (рисунок 11).
- Тонкость по потерям: при λ ≤ 0,35 СИСТЕМА_2 теряет чуть меньше заявок. При слабом
  потоке её накопитель на П2 ещё принимает заявки, которые в СИСТЕМЕ_1 уходят на П3
  без накопителя.
- Тонкость про Эрланга: при y₂ = 1,5 Эрланг (ν = 0,707) по сравнению с экспонентой
  **уменьшает потери** П2 (0,3654 против 0,3839), но очередь получается **длиннее**
  (1,8937 против 1,8341): принятых заявок больше. Очередь короче при малой
  вариации только без перегрузки (y < 1). Это хороший ответ, если спросят «почему
  Эрланг не помог».

# Шаг 9. Вопросы к защите

- **Когда процесс марковский?** Когда времена до переходов экспоненциальны
  (отсутствие последействия). Неэкспоненциальное обслуживание раскладывается на фазы.
- **Что такое интенсивность перехода, чему равна диагональ G?** g_ij = lim P_ij(Δ)/Δ;
  g_ii = −Σ g_ij, сумма строки равна 0.
- **Эргодичность?** Конечный неприводимый процесс без поглощающих и невозвратных
  состояний. У нас конечный накопитель, поэтому режим есть даже при y > 1.
- **Почему одно уравнение заменяется нормировкой?** Строки G линейно зависимы.
- **Почему π = вероятность заполненности?** Поток простейший, заявка застаёт систему
  в стационарном распределении (PASTA).
- **Почему поток к прибору простейший?** Случайное разрежение простейшего потока
  даёт простейший поток.
- **Как проверить результаты?** Σp = 1; ρ = λ'b; Литтл w = l/λ', u = m/λ';
  m = l + ρ; аналитика M/M/1/0 и M/M/1/r; произведение распределений для
  независимых приборов.
- **Почему у СИСТЕМЫ_2 загрузка выше, а она хуже?** Загрузка – доля занятых
  приборов, а приборов меньше. Критерий варианта – очередь, а не загрузка.
