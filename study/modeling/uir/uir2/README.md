## Вариант

Номер выдаётся как N1/N2/NG. N1 = N2 = 60, тот же номер, что в УИР 1. NG = 31, последние
две цифры P3331.

| | СИСТЕМА_1 (строка 60) | СИСТЕМА_2 (строка 60) |
|---|---|---|
| Приборы | 3, все экспоненциальные | 2, в одном Эрланг 2-го порядка |
| Накопители | 0 / 3 / 0 | 0 / 3 |
| q (табл. 2, строка 31) | 0,75 / 0,15 / 0,1 | 0,75 / 0,25 |

λ = 0,6 1/с, b = 10 с, μ = 0,1. N1 + N2 = 120 чётно, поэтому критерий берётся по N2, это (д).

## Толкования, которые пришлось выбрать

1. **Номер варианта.** По заданию он из трёх чисел, а у нас одно, 60. Принято
   N1 = N2 = 60. Если Авксентьева выдаёт N1 и N2 по-другому, меняется
   `solution/uir2/variant.py`, остальное пересчитается само.
2. **Где Эрланг в СИСТЕМЕ_2.** В задании сказано «в любом». Выбран П2, единственный прибор
   с накопителем. В П1 без накопителя закон обслуживания на характеристики не влияет:
   с Эрлангом в П1 получается 15 состояний и те же числа. Этот выбор сделал бы Эрланга
   формальностью.
3. **«Сумм.» для загрузки.** Взят коэффициент загрузки системы ρ = Σρᵢ/N, как у Алиева
   для M/M/2/1. Σρᵢ, среднее число занятых приборов, вынесено отдельной строкой.
4. **Суммарные времена** усреднены по принятым заявкам с весами λ'ᵢ/λ'. Суммарная
   вероятность потери π = 1 − λ'/λ.
5. **Время ожидания без Литтла.** Указание к форме 2 запрещает считать характеристики
   через фундаментальные зависимости. Поэтому w считается через вероятности: какое
   состояние застаёт заявка (PASTA) и сколько осталось обслуживать текущую. Литтл
   остаётся проверкой, совпадение точное.
