## 1. Марковский процесс с непрерывным временем

**Случайный процесс с дискретными состояниями** переходит из одного состояния в другое
в случайные моменты. **Марковский** процесс: будущее зависит только от текущего
состояния, а не от того, как процесс в него попал.

Процесс с непрерывным временем будет марковским, если время пребывания в каждом
состоянии **распределено экспоненциально**. Причина в отсутствии последействия:
сколько бы процесс уже ни пробыл в состоянии, оставшееся время распределено так же,
с тем же параметром. Поэтому в модели СМО нужны:

- простейший (пуассоновский) поток заявок;
- экспоненциальная длительность обслуживания, или неэкспоненциальная, разложенная
  на экспоненциальные фазы (см. п. 5).

**Интенсивность перехода** g_ij = lim_{Δ→0} P_ij(Δ)/Δ. При экспоненциальном времени
перехода это параметр экспоненты: вероятность перехода за малое Δ ≈ g_ij·Δ.

## 2. Матрица интенсивностей G

- g_ij (i ≠ j): интенсивность перехода i → j, ≥ 0;
- g_ii = −Σ_{j≠i} g_ij, так что **сумма каждой строки равна нулю**.

В WinMark диагональ не вводится и считается сама. Строка из одних нулей
(поглощающее состояние) недопустима.

## 3. Уравнения Колмогорова и стационарный режим

Нестационарный режим: dp_j(t)/dt = Σ_i p_i(t)·g_ij, нужны начальные вероятности.

**Эргодическое свойство**: существует предел p_i = lim p_i(t), не зависящий от начальных
условий. Для процесса с непрерывным временем и конечным числом состояний оно есть,
если процесс **транзитивный**: из любого состояния достижимо любое другое, нет
невозвратных и поглощающих состояний.

Стационарные вероятности находятся из СЛАУ:

```
Σ_i p_i·g_ij = 0,  j = 1…n     (P·G = 0)
Σ_i p_i = 1                    (нормировка)
```

Уравнения P·G = 0 линейно зависимы (строки G дают в сумме ноль), поэтому одно из них
заменяют нормировкой.

**Правило составления по графу**: для каждого состояния поток вероятности «наружу»
равен потоку «внутрь»:

```
p_j · (сумма интенсивностей всех стрелок из E_j) = Σ p_i · (интенсивность стрелки E_i → E_j)
```

## 4. Этапы разработки марковской модели (Алиев, 5.4)

1. Описание системы и предположения (поток, обслуживание, дисциплины буферизации и обслуживания).
2. **Кодирование состояний**: набор параметров, который однозначно задаёт состояние.
3. **Размеченный граф переходов**: стрелки с интенсивностями.
4. **Матрица интенсивностей**.
5. **Система уравнений** и её решение.
6. **Характеристики** через стационарные вероятности.

## 5. Базовые модели и формулы Алиева

Обозначения: λ – интенсивность потока, b – средняя длительность обслуживания,
μ = 1/b, y = λb – нагрузка.

### M/M/1/0 (без накопителя)

Состояния E0 (свободен), E1 (занят). λ·p0 = μ·p1:

```
p0 = 1/(1+y),   p1 = y/(1+y)
ρ = p1,  π = p1,  λ' = λ(1−π),  m = p1,  u = m/λ' = b
```

Вероятность потери равна вероятности того, что прибор занят.

### M/M/1/r (накопитель ёмкостью r)

Состояния k = 0…r+1 (число заявок в системе), процесс гибели и размножения:

```
p_k = y^k (1−y) / (1 − y^(r+2)),  y ≠ 1;    p_k = 1/(r+2),  y = 1
ρ = 1 − p0
l = Σ_{k=2}^{r+1} (k−1)·p_k
m = Σ k·p_k = l + ρ
π = p_{r+1}
λ' = λ(1−π),   w = l/λ',   u = w + b
```

При r конечном установившийся режим есть при **любой** нагрузке, в том числе y > 1:
лишние заявки просто теряются.

### M/M/N/0, M/M/2/1 (многоканальные с общим накопителем)

Загрузка системы ρ = k'/N, где k' = Σ (число занятых приборов)·p, то есть среднее число
работающих приборов. В УИР 2 по этой формуле считается строка «Сумм.» загрузки.

## 6. Неэкспоненциальное обслуживание: метод фаз

### Эрланг k-го порядка (ν = 1/√k < 1)

Длительность складывается из k экспоненциальных фаз, каждая с интенсивностью **kμ = k/b**
(тогда среднее b). Состояние прибора дополняется **номером фазы**: «2₁» значит две заявки,
текущая на первой фазе. Переходы:

- поступление: n₍f₎ → (n+1)₍f₎ с λ (фаза не меняется);
- фаза f → f+1 с kμ;
- после последней фазы заявка уходит: n₍k₎ → (n−1)₍1₎ с kμ.

Пример у Алиева: АЗС (заправка + оплата = две фазы), с. 64–65 теории.

### Гиперэкспоненциальный закон (ν > 1)

Длительность с вероятностью q экспоненциальная с μ₁, иначе с μ₂. В состоянии
фиксируется, какая из двух «ветвей» идёт. В нашем варианте не нужен.

### Инвариантность систем с отказами

В СМО **без накопителя** (M/G/1/0, M/G/N/0) стационарные вероятности числа занятых
приборов зависят только от среднего b, а не от закона (формула Эрланга B).
Поэтому Эрланг в приборе без накопителя ничего не меняет в характеристиках.

## 7. Характеристики (форма 2)

Для прибора i с потоком λᵢ = qᵢλ и накопителем rᵢ:

| Характеристика | Формула |
|---|---|
| Нагрузка | yᵢ = λᵢ·b |
| Загрузка | ρᵢ = Σ p(E) по состояниям, где nᵢ > 0 |
| Длина очереди | lᵢ = Σ (nᵢ − 1)·p(E) по nᵢ > 1 |
| Число заявок | mᵢ = Σ nᵢ·p(E) |
| Вероятность потери | πᵢ = Σ p(E) по nᵢ = rᵢ + 1 (накопитель полон) |
| Производительность | λ'ᵢ = λᵢ(1 − πᵢ) |
| Время ожидания | wᵢ = l/λ' (Литтл) **или** через вероятности, см. ниже |
| Время пребывания | uᵢ = wᵢ + b |

Суммарные: Y = Σyᵢ; ρ = Σρᵢ/N; l = Σlᵢ; m = Σmᵢ; λ' = Σλ'ᵢ; π = 1 − λ'/λ;
w = Σλ'ᵢwᵢ/λ'; u = Σλ'ᵢuᵢ/λ' (Алиев, суммарный поток, с. 39–40).

**Указание задания**: характеристики считать через вероятности, без формул Литтла;
фундаментальные зависимости только для проверки. Время ожидания тоже можно
посчитать через вероятности. Простейший поток видит систему в стационарном
распределении (свойство PASTA). Принятая заявка застаёт у прибора n заявок
(текущая на фазе f) с вероятностью p(E)/(1−π) и ждёт
`(n−1)·b + остаток текущей`. Остаток при экспоненте равен b, при Эрланге-k на фазе f
он равен (k−f+1)·b/k. Отсюда

```
wᵢ = b/(1−πᵢ) · Σ_{0<nᵢ≤rᵢ} τ(E)·p(E),   τ(E) = (nᵢ − 1) + (k − f + 1)/k
```

Проверки: w = l/λ' (Литтл), ρ = λ'·b (что принято, то и обслужено), m = l + ρ.

## 8. Программа MARK (WinMark)

Считает стационарные вероятности марковского процесса по матрице интенсивностей
и характеристики по формулам, которые вводит пользователь. Умеет варьировать
элементы матрицы (5 точек) и строить графики. Подробно в справке WinMark.chm
и [walkthrough.md, шаг 7](walkthrough.md#шаг-7-winmark).
