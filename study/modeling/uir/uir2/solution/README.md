# УИР 2: расчётная часть

На входе вариант N1/N2/NG, на выходе стационарные вероятности (форма 1), характеристики
(форма 2), графы переходов, матрицы интенсивностей и сравнительные графики для typst-отчёта.

## Запуск

numpy в системном python3 собран под x86_64 и не импортируется, поэтому запуск через uv:

```bash
uv run --no-project --with matplotlib python -m uir2 -v 60/60/31 --typst ../../../reports/uir2
uv run --no-project --with matplotlib --with pytest pytest -q
```

| Ключ | Назначение |
|---|---|
| `-v, --variant` | вариант `N1/N2/NG`, по умолчанию `60/60/31` |
| `--law-device` | номер прибора СИСТЕМЫ_2 с законом Эрланга (по умолчанию: прибор с самым большим накопителем) |
| `--typst` | каталог отчёта: туда пишутся `data.json` и `plots/` |

## Модули

| Файл | Что делает |
|---|---|
| `uir2/variants.py` | таблицы 1 (80 вариантов) и 2 из задания, правило выбора критерия |
| `uir2/systems.py` | вариант → набор приборов (вероятность, накопитель, число фаз) |
| `uir2/model.py` | состояния, интенсивности переходов, решение pG = 0 методом Гаусса, характеристики |
| `uir2/plots.py` | размеченный граф переходов, графики при варьировании λ |
| `uir2/typst_export.py` | `data.json` для отчёта: формы, формулы через p_j, проверки, выводы |

Не поддерживаются: гиперэкспоненциальный закон (для него нужен ещё параметр q) и общий
накопитель перед всеми приборами. Для варианта 60/60 не нужно ни то, ни другое.
