# УИР 2: расчётная часть

Считает обе системы варианта 60/60/31: строит граф состояний, точно решает СЛАУ
в дробях, заполняет формы 1 и 2 и проверяет результат вторым способом. Ещё варьирует λ,
рисует графики и выгружает данные в typst-отчёт.

## Запуск

```bash
python3 -m pip install -r requirements.txt
python3 -m uir2 --typst ../../../reports/uir2
```

В `out/report.md` попадает сводка: формы 1 и 2, таблицы ввода матриц и формулы для WinMark,
проверки, выводы. С ключом `--typst` в `reports/uir2/` пишутся `data.json` и `plots/`.

## Модули

| Файл | Что делает |
|---|---|
| `uir2/variant.py` | исходные данные (строки 60 и 31 таблиц 1 и 2), критерий, состав систем |
| `uir2/model.py` | кодирование состояний и граф переходов, Эрланг-k методом фаз |
| `uir2/ctmc.py` | матрица G и стационарные вероятности методом Гаусса в дробях |
| `uir2/metrics.py` | характеристики через вероятности без Литтла, формулы для WinMark и их вычисление |
| `uir2/analytic.py` | формулы Алиева для M/M/1/0 и M/M/1/r, M/E_k/1/K через вложенную цепь |
| `uir2/analysis.py` | полный прогон, проверки, варьирование λ, выбор по критерию, тексты выводов |
| `uir2/plots.py` | схемы систем, размеченные графы, графики от λ |
| `uir2/report.py`, `uir2/typst_export.py` | markdown-сводка и `data.json` для отчёта |

## Проверки

Вероятности точные, поэтому совпадения проверяются равенством, без допуска:

- Σp = 1 и P·G = 0;
- распределение каждого прибора совпадает с M/M/1/0 и M/M/1/3 по Алиеву, а у П2 СИСТЕМЫ_2
  с вложенной цепью M/E₂/1/3, посчитанной без фаз;
- в СИСТЕМЕ_1 p(n₁,n₂,n₃) = p₁·p₂·p₃;
- Литтл w = l/λ' и u = m/λ', ρ = λ'b, m = l + ρ;
- формулы для WinMark, вычисленные как строки, дают те же значения.

## Тесты

```bash
python3 -m unittest test_uir2 -v
```

22 теста: параметры варианта, решатель, аналитика, формулы WinMark, устойчивость выбора
на всём диапазоне λ. Отдельно проверено, что Эрланг в П1 ничего не меняет, а в П2 при
перегрузке снижает потери, но удлиняет очередь.
