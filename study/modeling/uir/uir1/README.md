# УИР 1

Статистический анализ числовой последовательности. **Вариант 60.** Дедлайн **05.11.2026**.

Результат расчёта по варианту 60: м.о. = 312,85, ν = 0,6274, закон —
**гипоэкспоненциальный** (k = 3). Последовательность **не случайная**:
автокорреляция r₁ = 0,686 при пороге 0,113, на графике виден возрастающий тренд.

Дополнительно:

- [Лекция 3 «Имитационное моделирование»](https://lms.itmo.ru/mod/resource/view.php?id=6924),
  **с. 4–7** — методы формирования псевдослучайных величин. Нужна для шага 7:
  с. 4–5 генераторы равномерных в (0;1) (квадратов, произведений, конгруэнтные),
  с. 6 аналитический метод `x = −(1/α)·ln s` (это и есть метод обратной функции),
  табличный метод и определения Эрланга/гиперэкспоненты как суммы и смеси.
  Остальные 22 страницы — про GPSS, к УИР 1 не относятся.
- [Алиев Т.И. Основы моделирования дискретных систем](https://books.ifmo.ru/book/445/osnovy_modelirovaniya_diskretnyh_sistem.htm)
  — основной учебник курса, если нужны полные выводы.

Чего в материалах курса **нет**: числа интервалов гистограммы (формула Стёрджеса) —
в лекциях гистограмма разбирается только как `QTABLE` в GPSS. Этот пункт приходится
брать из общей статистики.
