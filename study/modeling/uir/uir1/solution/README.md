# УИР 1 — расчётная часть

Параметризованный расчёт: на входе номер варианта, на выходе формы 1–3,
графики 1–3, выбранный закон распределения и готовый markdown-отчёт.

Покрывает **все 360 вариантов** — задание для них одинаковое, отличаются только
данные (столбец из 300 наблюдений).

## Установка и запуск

```bash
python3 -m pip install -r requirements.txt
python3 -m uir1 --variant 60
```

Отчёт появится в `out/variant-060/`: `report.md`, `plots/*.png`, `form1.csv`, `form2.csv`.

### Ключи

| Ключ | Назначение |
|---|---|
| `-v, --variant` | номер варианта, 1…360 (обязательный) |
| `-o, --out` | каталог для результатов (по умолчанию `./out`) |
| `-x, --xlsx` | файл вариантов (по умолчанию из `materials/lms/`) |
| `-l, --law` | принудительный закон: `uniform`, `exponential`, `erlang`, `hypoexponential`, `hyperexponential`; по умолчанию `auto` — выбор по ν |
| `-q` | параметр q гиперэкспоненциального закона |
| `--seed` | seed генератора (по умолчанию фиксирован — прогон воспроизводим) |
| `--list` | сводка по всем 360 вариантам: m̃, ν, выбранный закон |

## Выбор закона

| ν | Закон |
|---|---|
| `ν > 1,05` | гиперэкспоненциальный, `q = 1/(1+ν²)` |
| `0,95 ≤ ν ≤ 1,05` | экспоненциальный |
| `ν < 0,95`, `1/ν²` близко к целому | нормированный Эрланга |
| `ν < 0,95`, `1/ν²` далеко от целого | гипоэкспоненциальный из `k = ⌈1/ν²⌉` фаз |

Последняя строка — не самодеятельность: задание требует аппроксимации **по двум
моментам**, а округление `k` до целого искажает второй. Гипоэкспонента из `k` фаз
(`k−1` одинаковых плюс одна другая) подгоняет оба момента точно при любом `ν < 1`,
поэтому Эрланг остаётся только там, где `1/ν²` и так почти целое.

Расклад по всем 360 вариантам: гиперэкспоненциальный — 164, гипоэкспоненциальный —
164, экспоненциальный — 26, Эрланга — 6.

## Что нужно доделать руками

Скрипт считает и рисует, но **отчёт за тебя не сдаст**:

- **Характер последовательности** (график 1) определяется автоматически лишь грубо —
  сравнением средних половин. Периодичность и длину периода надо смотреть глазами.
- **Выбор между Эрлангом и равномерным** при `ν < 1/√3` делается по виду гистограммы,
  а не по числу. Отчёт об этом предупреждает, решение за тобой.
- **Титульный лист** и оформление по требованиям кафедры.
- **Демонстрация генератора на защите** — запустить `python3 -m uir1 -v <номер>`
  и показать раздел 6 отчёта.

## Точность подгонки

При `ν < 1` оба момента воспроизводятся точно (расхождение порядка 1e-14).
Единственное место, где остаётся расхождение, — экспоненциальный закон: он берётся
при `0,95 ≤ ν ≤ 1,05`, и на краях допуска второй момент отклоняется до 5 %.
Это осознанный выбор в пользу простого закона, ожидаемого курсом при `ν ≈ 1`;
отчёт печатает точное отклонение, и его стоит упомянуть в выводах.

Вариант 60 (рабочий): `ν = 0,6274`, `1/ν² = 2,54`. Эрланг с `k = 3` дал бы
`ν = 0,5774` — ошибка 8 %. Гипоэкспонента из 3 фаз (две по 135,63 и одна 41,59)
даёт ровно 0,6274.
