# Теория для УИР 1

Источники: «Обработка результатов имитационного моделирования» (LMS 7289),
презентация «Статистическая обработка результатов измерений» (6917),
«Элементы теории вероятностей» (7276). Всё лежит в `../../materials/lms/`.

Обозначения: `X₁…Xₙ` — заданная числовая последовательность (ЧП), `n` — объём выборки,
`m̃` — оценка мат. ожидания, `D̃` — оценка дисперсии, `σ̃` — СКО, `ν` — коэффициент вариации.

---

## 1. Точечные оценки

**Оценка мат. ожидания** — среднее арифметическое:

```
m̃ = (1/n) · Σᵢ₌₁ⁿ Xᵢ
```

Она состоятельная (по закону больших чисел сходится к `m`) и несмещённая (`M[m̃] = m`).
Дисперсия самой оценки: `D[m̃] = D/n` — отсюда и берётся вся точность.

**Оценка дисперсии** — обязательно с `n−1` в знаменателе, иначе оценка смещённая:

```
D̃ = Σᵢ₌₁ⁿ (Xᵢ − m̃)² / (n − 1)
```

Равносильная форма через второй начальный момент:

```
D̃ = [ Σᵢ₌₁ⁿ Xᵢ²/n  −  m̃² ] · n/(n−1)
```

где `n/(n−1)` — поправочный множитель Бесселя. При больших `n` он близок к 1.

**СКО и коэффициент вариации:**

```
σ̃ = √D̃          ν = σ̃ / m̃        (при m̃ > 0)
```

`ν` — центральная величина всей работы: именно он определяет выбор аппроксимирующего закона.

⚠️ В Excel: `СТАНДОТКЛОН.В` / `ДИСП.В` (выборочные, с `n−1`), **не** `.Г`.
В Python: `statistics.stdev`, `numpy.std(x, ddof=1)` — по умолчанию `numpy.std` даёт `ddof=0`,
это частая ошибка.

## 2. Доверительные интервалы

Истинное `m` неизвестно; оценка `m̃` от него отличается. Доверительный интервал — интервал,
в который `m` попадает с заданной вероятностью `p`:

```
Pr(m̃ − Δ < m < m̃ + Δ) = p
```

`Δ` — **полуинтервал** (именно его требует форма 1, в виде `±<значение>`).

По центральной предельной теореме `m̃` распределена приблизительно нормально, поэтому:

```
σ̃_m = √(D̃ / n)        — СКО самой оценки мат. ожидания
Δ_p  = t_p · σ̃_m
```

Границы: `m_н = m̃ − Δ_p`, `m_в = m̃ + Δ_p`.

**Относительная погрешность** (её тоже вносят в отчёт):

```
δ = (Δ / m̃) · 100 %
```

⚠️ **Расхождение, о котором стоит знать.** Методичка даёт `t_p` из **нормального**

неизвестной дисперсии и малом `n` полагается распределение **Стьюдента** (для `n = 10`,

иначе числа не сойдутся с ожидаемыми. Но в выводах это хорошее место показать понимание:
упомянуть, что для малых выборок нормальная аппроксимация занижает интервал.
Табличное значение `0,9 → 1,643` тоже слегка огрублено, точное `1,645`.

## 4. Автокорреляционный анализ

**Коэффициент корреляции** двух величин:

```
r_XY = cov_XY / (σ_X · σ_Y)
     = Σ(xᵢ − M[X])(yᵢ − M[Y]) / √( Σ(xᵢ − M[X])² · Σ(yᵢ − M[Y])² )
```

**Коэффициент автокорреляции** со сдвигом `k` — корреляция ряда с самим собой, сдвинутым на `k`:

```
r_Xk = Σᵢ (xᵢ − M[X])(x_{i+k} − M[Xk]) / √( Σ(xᵢ − M[X])² · Σ(x_{i+k} − M[Xk])² )
```

При `n >> k` упрощается (методичка разрешает эту форму):

```
r_Xk ≈ Σᵢ (xᵢ − M[X])(x_{i+k} − M[X]) / Σᵢ (xᵢ − M[X])²
```

Считать для сдвигов `k = 1…10` (форма 3).

**Как трактовать.** Для по-настоящему случайной последовательности все `r_Xk` колеблются
около нуля. Ориентир значимости — `±1,96/√n` (для `n = 300` это ≈ ±0,113): если коэффициенты
систематически выходят за эту границу, последовательность случайной считать нельзя.
В примере из презентации коэффициенты держатся на уровне 0,2–0,4 — это явная
автокоррелированность, и вывод там отрицательный.

В Excel: `КОРРЕЛ(диапазон1; диапазон2)` с двумя сдвинутыми диапазонами.

## 5. Гистограмма распределения частот

Диапазон `[min, max]` разбивается на `L` интервалов. Число интервалов — по Стёрджесу:

```
L = 1 + 3,322 · lg n      (для n = 300 → L ≈ 9–10)
```

По оси Y — частота (или относительная частота `nⱼ/n`). Для сравнения с плотностью
распределения на графике 3 гистограмму надо **нормировать**: делить на `n · Δx`,
где `Δx` — ширина интервала. Иначе гистограмма и `f(x)` окажутся в разных масштабах
и график будет бессмысленным.

## 6. Выбор аппроксимирующего закона по ν

Ключевая развилка работы. Аппроксимация идёт **по двум моментам** — `m̃` (обозначим `t`) и `ν`:

| ν | Закон |
|---|---|
| `ν = 0` | детерминированная величина |
| `0 < ν < 1/√3 ≈ 0,577` | равномерный (возможен) |
| `0 < ν < 1` | **нормированный Эрланга** k-го порядка или гипоэкспоненциальный |
| `ν = 1` | **экспоненциальный** |
| `ν > 1` | **гиперэкспоненциальный** |

Выбор подтверждается видом гистограммы, а не только числом.

### 6.1. Равномерный закон

```
f(x) = 1/(b−a),  a ≤ x ≤ b
F(x) = (x−a)/(b−a)
M = (a+b)/2      D = (b−a)²/12      σ = (b−a)/(2√3)      ν = (b−a)/(√3(a+b))
```

Параметры по `m̃` и `σ̃`: `a = m̃ − σ̃√3`, `b = m̃ + σ̃√3`.

### 6.2. Экспоненциальный закон

```
F(x) = 1 − e^(−αx)      f(x) = α·e^(−αx)
M = 1/α      D = 1/α²      σ = 1/α      ν = 1  (всегда)
```

Параметр: `α = 1/t`.

### 6.3. Нормированное распределение Эрланга (ν < 1)

Это `k` последовательных экспоненциальных фаз, каждая со средним `t/k`.
Нормированное — значит суммарное среднее равно `t` (в обычном Эрланге среднее `k/α`).

```
M = 1/α      D = 1/(k·α²)      σ = 1/(α√k)      ν = 1/√k
```

Подбор параметров по заданным `t` и `ν`:

```
k = 1/ν²        (округлить до целого)
M[Ek] = t       каждая фаза имеет среднее t/k
```

Опорные значения: `k=2 → ν=0,707`, `k=3 → ν=0,577`, `k=4 → ν=0,5`, `k=16 → ν=0,25`.

Если `1/ν²` далеко от целого, точная подгонка обоих моментов делается
**гипоэкспоненциальным** распределением (фазы с разными интенсивностями) —
задание это прямо допускает.

### 6.4. Гиперэкспоненциальное распределение (ν > 1)

Две экспоненциальные фазы, выбираемые случайно: с вероятностью `q` — фаза со средним `t₁`,
с вероятностью `1−q` — со средним `t₂`.

```
F(x) = 1 − q·e^(−x/t₁) − (1−q)·e^(−x/t₂)
f(x) = (q/t₁)·e^(−x/t₁) + ((1−q)/t₂)·e^(−x/t₂)
```

У системы два уравнения (`t` и `ν`) и три неизвестных (`q`, `t₁`, `t₂`), поэтому `q`
задаётся свободно в допустимых границах:

```
q ≤ 2/(1 + ν²)

t₁ = [ 1 + √( (1−q)/(2q) · (ν² − 1) ) ] · t

t₂ = [ 1 − √( q/(2(1−q)) · (ν² − 1) ) ] · t
```

⚠️ `q` надо выбирать так, чтобы `t₂ > 0` — иначе параметры бессмысленны.
Проверка обязательна: подставить `t₁`, `t₂`, `q` обратно и убедиться, что
`q·t₁ + (1−q)·t₂ = t` и что расчётное `ν` совпало с исходным.

### 6.5. Сводная таблица числовых характеристик

| Распределение | M[X] | D[X] | ν[X] |
|---|---|---|---|
| Равномерное | `(a+b)/2` | `(b−a)²/12` | `(b−a)/(√3(a+b))` |
| Экспоненциальное | `1/α` | `1/α²` | `1` |
| Эрланга | `k/α` | `k/α²` | `1/√k` |
| Эрланга нормированное | `1/α` | `1/(kα²)` | `1/√k` |
| Гиперэкспоненциальное | `Σqᵢ/αᵢ` | `α₂[X] − (M[X])²` | `> 1` |
| Пуассона | `a` | `a` | `1/√a` |
| Геометрическое | `ρ/(1−ρ)` | `ρ/(1−ρ)²` | `1/√ρ` |

## 7. Генератор случайных величин

Базовый приём — **метод обратной функции**: если `U ~ R(0,1)`, то `X = F⁻¹(U)`
распределена по закону `F`.

| Закон | Формула генерации |
|---|---|
| Равномерный | `x = a + (b−a)·U` |
| Экспоненциальный | `x = −t·ln(U)` |
| Эрланга нормир. (k фаз) | `x = −(t/k)·ln(U₁·U₂·…·U_k)` |
| Гиперэкспоненциальный | `если U ≤ q: x = −t₁·ln(U′), иначе x = −t₂·ln(U′)` |

В Excel `U` = `СЛЧИС()`. Для гиперэкспоненциального нужны **два независимых** обращения
к `СЛЧИС()` — одно на выбор фазы, второе на саму экспоненту; переиспользовать одно
и то же значение нельзя, появится искусственная зависимость.

## 8. Сравнение сгенерированной ЧП с заданной

1. Числовые характеристики сгенерированной ЧП по тем же формулам, для тех же
   объёмов 10/20/50/100/200/300 → **форма 2**, с отклонениями в % от заданной ЧП.
2. Автокорреляция сгенерированной ЧП → **форма 3**.
   У корректного генератора коэффициенты должны быть около нуля — это как раз
   контраст с заданной ЧП, если та оказалась коррелированной.
3. График 3: гистограмма заданной ЧП + плотность `f(x)` аппроксимирующего закона
   (не забыть нормировку из п. 5).
4. Коэффициент корреляции между заданной и сгенерированной последовательностями
   по формуле `r_XY` из п. 4.

⚠️ Логическая ловушка последнего пункта: `r_XY` между двумя независимыми выборками
**обязан** быть около нуля, и это правильный результат, а не провал аппроксимации.
Близость законов проверяется совпадением моментов и гистограммы, а не корреляцией
между реализациями. В выводах это надо написать явно.
