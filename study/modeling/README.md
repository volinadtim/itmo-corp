## Баллы (БАРС)

| | ЛР1 | ЛР2 | ЛР3 | ЛР4 | ТР1 | ТР2 | ТР3 | ИтТ/Экз | ТЛ4 | Итого | ЛК | Всего |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| Max | 5 | 5 | 10 | 10 | 10 | 10 | 15 | 25 | 10 | 100 | 10 | 110 |
| Min % | | | | | 20% | 20% | 20% | 40% / 60% | | | | |
| 1% = | | | | | 0,125 | 0,125 | 0,1875 | 0,417 / 0,625 | | | | |

- **Тесты**: результат в процентах, в баллы переводится только то, что **выше Min%**.
  ТР1 (~4-е занятие) — Раздел 1 + ТВ + марковские процессы; ТР2 (~6-е) — Раздел 2 + вопросы ТР1;
  ТР3 (7-е) — Раздел 3 + вопросы ТР1 и ТР2. Каждый следующий тест включает предыдущие.
- **ИтТ или Экзамен**: итоговое тестирование — только для претендующих на «автомат»
  и только если **все ЛР сданы и защищены**. Идёшь на экзамен ради повышения — баллы ИтТ снимаются.
  40% — порог тройки на основном экзамене, 60% — на дополнительном.
- **ТЛ4** — письменные тесты на лекциях, до 10 баллов. Лекции реально дают баллы: в журнале
  у половины группы стоит 4,0 за лекции, у остальных 0.
- **ЛК** (личностные качества, 0–10) — посещаемость + сроки/качество ЛР. Не участвовал
  в ИтТ/экзамене → ЛК не начисляют.

Вывод: тесты + лекции = 45 из 100 без единой лабы. Лекции пропускать нельзя.

## Разделы курса

1. **Общие вопросы моделирования** — системы, модели, классификация, параметризация.
2. **Модели дискретных систем** — СМО, дисциплины буферизации/обслуживания, символика Кендалла, СеМО.
3. **Марковские модели** — случайные процессы, граф переходов, дискретное/непрерывное время.
4. **Имитационное моделирование** — GPSS World, AnyLogic, генерация псевдослучайных величин.
5. **Анализ свойств базовых моделей** — многоканальные СМО, неоднородный поток, приоритеты (ОП/АП/СП).
6. **Сетевые модели** — коэффициенты передач, разомкнутые/замкнутые сети.
7. **Модели компьютерных систем** — серверная обработка, кластеры, звено передачи данных.

Аббревиатуры курса (СМО, СеМО, ДБ, ДО, ОП/АП/СП...) — [materials/abbreviations.md](materials/abbreviations.md).
