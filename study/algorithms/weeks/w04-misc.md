### 4.58. Рекуррентность \(T(n) = 3T(n/2) + n^2\)

**Условие.** Дано \(T(n) = 3T(n/2) + n^2\). Можно считать \(T(1) = 1\) или выбрать удобную базу. Найти \(\Theta\)-асимптотику и доказать её по индукции.

> Источник теории: [neerc.ifmo.ru/wiki — Мастер-теорема](https://neerc.ifmo.ru/wiki/index.php?title=Мастер-теорема)

#### 1. Догадка (мастер-теорема / дерево рекурсии)

Форма \(T(n) = a\,T(n/b) + n^c\) с \(a = 3\), \(b = 2\), \(c = 2\).

\[
\log_b a = \log_2 3 \approx 1.585 < 2 = c.
\]

Случай \(c > \log_b a\): работа на корне доминирует, \(T(n) = \Theta(n^2)\).

Дерево рекурсии (считаем \(n = 2^k\)): \(\log_2 n\) уровней, на уровне \(i\) ровно \(3^i\) вершин размера \(n/2^i\). Стоимость уровня:

\[
3^i \cdot \Bigl(\frac{n}{2^i}\Bigr)^2 = n^2 \Bigl(\frac{3}{4}\Bigr)^i.
\]

Сумма геометрической прогрессии со знаменателем \(3/4 < 1\):

\[
T(n) = n^2 \sum_{i=0}^{k-1} \Bigl(\frac{3}{4}\Bigr)^i + 3^k T(1)
= 4n^2\Bigl(1 - \bigl(\tfrac{3}{4}\bigr)^k\Bigr) + n^{\log_2 3}\,T(1).
\]

Так как \(\log_2 3 < 2\), второе слагаемое \(o(n^2)\), откуда \(T(n) \sim 4n^2\).

Это **не доказательство** для задачи: мастер-теорему на зачёте могут не принять как единственный аргумент. Ниже — индукция, как просят в условии.

Дальше считаем \(n = 2^k\) (это разрешено: удобная база и стандартное соглашение для таких рекуррентностей). \(T(1) = 1\).

#### 2. Верхняя оценка: \(T(n) = O(n^2)\)

Утверждение: существует константа \(c > 0\), такая что \(T(n) \le c\,n^2\) для всех \(n = 2^k\).

**База.** \(n = 1\): \(T(1) = 1 \le c\). Достаточно \(c \ge 1\).

**Переход.** Пусть неравенство верно для \(n/2\). Тогда

\[
T(n) = 3T\Bigl(\frac{n}{2}\Bigr) + n^2 \le 3c\Bigl(\frac{n}{2}\Bigr)^2 + n^2 = n^2\Bigl(\frac{3c}{4} + 1\Bigr).
\]

Нужно \(\frac{3c}{4} + 1 \le c\), то есть \(1 \le c/4\), то есть \(c \ge 4\).

Берём \(c = 4\). База выполняется (\(1 \le 4\)), переход превращается в равенство:

\[
3\cdot 4\cdot\frac{n^2}{4} + n^2 = 3n^2 + n^2 = 4n^2.
\]

Значит \(T(n) \le 4n^2\) для всех степеней двойки. Итого \(T(n) = O(n^2)\).

#### 3. Нижняя оценка: \(T(n) = \Omega(n^2)\)

Утверждение: существует константа \(d > 0\), такая что \(T(n) \ge d\,n^2\).

Самый короткий вариант: \(T(n) = 3T(n/2) + n^2 \ge n^2\), поэтому подойдёт \(d = 1\).

Если писать «симметрично» верхней оценке:

\[
T(n) \ge 3d\Bigl(\frac{n}{2}\Bigr)^2 + n^2 = n^2\Bigl(\frac{3d}{4} + 1\Bigr).
\]

Нужно \(\frac{3d}{4} + 1 \ge d\), то есть \(d \le 4\). База \(T(1) = 1 \ge d\) даёт \(d \le 1\). Берём \(d = 1\).

Значит \(T(n) \ge n^2\), то есть \(T(n) = \Omega(n^2)\).

#### 4. Итог

\[
n^2 \le T(n) \le 4n^2 \qquad\Rightarrow\qquad T(n) = \Theta(n^2).
\]

**Типичная ошибка.** Пытаться доказать \(T(n) \le n^2\): переход ломается, потому что \(3\cdot(n/2)^2 + n^2 = 1.75n^2 > n^2\). Константа должна быть достаточно большой (\(c \ge 4\)), чтобы «поглотить» добавку \(+n^2\).

**Замечание про не степени двойки.** Если определять \(T(n) = 3T(\lfloor n/2\rfloor) + n^2\) для всех \(n\), та же асимптотика сохраняется: \(\lfloor n/2\rfloor\) отличается от \(n/2\) на \(O(1)\), и индукция проводится по всем \(n\) с той же парой констант (иногда базу проверяют до небольшого \(n_0\), а не только в \(n=1\)).

### 4.59. Точка встречи: минимум суммы расстояний

**Условие.** На прямой n друзей в точках \(x_1, \dots, x_n\). Найти точку встречи \(m\), минимизирующую \(\sum_{i=1}^n |x_i - m|\). Время: \(O(n \log n)\).

#### Идея

Функция \(f(m) = \sum |x_i - m|\) — кусочно-линейная, выпуклая. Производная (вернее, субградиент) равна количеству друзей слева от \(m\) минус количество справа. Минимум в точке, где слева и справа **поровну** — то есть в **медиане**.

**Если n нечётное** — единственная точка: центральный элемент отсортированного массива.
**Если n чётное** — любая точка между двумя центральными даёт одинаковую сумму.

#### Алгоритм

1. **Отсортировать** массив за \(O(n \log n)\).
2. **Вернуть** \(x_{\lfloor n/2\rfloor}\) (нумерация с 0). Если нужно само значение минимума — посчитать сумму расстояний до медианы за O(n) (можно совместить с поиском или через префиксные суммы).

#### Доказательство

Для \(m < x_i\): \(|x_i - m| = x_i - m\). Для \(m > x_i\): \(|x_i - m| = m - x_i\).

Пусть массив отсортирован по возрастанию. Если \(m\) лежит между \(x_k\) и \(x_{k+1}\), то:

\[
f(m) = \sum_{i=1}^{k} (m - x_i) + \sum_{i=k+1}^{n} (x_i - m)
      = (2k - n)\,m + \text{const}.
\]

Производная по \(m\) равна \(2k - n\). При \(k < n/2\) производная отрицательна (функция убывает); при \(k > n/2\) положительна (возрастает). Минимум при \(k = \lfloor n/2 \rfloor\).

#### Реализация (Python)

```python
def best_meeting_point(x: list[int]) -> int:
    x_sorted = sorted(x)
    return x_sorted[len(x_sorted) // 2]

def min_total_distance(x: list[int]) -> int:
    x_sorted = sorted(x)
    m = x_sorted[len(x_sorted) // 2]
    return sum(abs(v - m) for v in x_sorted)
```

Время: \(O(n \log n)\) на сортировку, \(O(n)\) на сумму. Память: \(O(n)\) или \(O(1)\) если сортировать in-place.

#### Вариация

В задаче 4.60 (следующая) вместо суммы расстояний — **сумма квадратов расстояний**. Там оптимальная точка — **среднее арифметическое**.

### 4.60. Точка встречи: минимум суммы квадратов расстояний

**Условие.** На прямой n друзей в точках \(x_1, \dots, x_n\). Найти точку \(m\), минимизирующую \(\sum_{i=1}^n (x_i - m)^2\). Время: \(O(n \log n)\).

#### Идея

Минимизируем \(f(m) = \sum (x_i - m)^2\). Это парабола ветвями вверх.

\[
f(m) = \sum (x_i^2 - 2x_i m + m^2) = n\,m^2 - 2m\sum x_i + \sum x_i^2.
\]

Производная:

\[
f'(m) = 2n\,m - 2\sum x_i = 0 \quad\Rightarrow\quad m = \frac{1}{n}\sum_{i=1}^n x_i.
\]

Оптимум — **среднее арифметическое**. Сортировка не нужна — достаточно одного прохода.

#### Алгоритм

1. Посчитать сумму \(\displaystyle S = \sum_{i=1}^n x_i\) за \(O(n)\).
2. Вернуть \(m = S / n\).

Время: \(O(n)\) (а не \(O(n \log n)\) — в условии мягкая оценка). Память: \(O(1)\).

#### Сравнение с 4.59

| Задача | Минимизируем | Оптимальная точка | Сложность |
|--------|-------------|-------------------|-----------|
| 4.59 | \(\sum \|x_i - m\|\) | **медиана** | \(O(n \log n)\) |
| 4.60 | \(\sum (x_i - m)^2\) | **среднее** | \(O(n)\) |

Среднее чувствительно к выбросам (квадрат растягивает большие отклонения), медиана — устойчива.

#### Реализация (Python)

```python
def best_meeting_point_squared(x: list[int]) -> float:
    return sum(x) / len(x)

def min_squared_distance(x: list[int]) -> float:
    m = sum(x) / len(x)
    return sum((v - m) ** 2 for v in x)
```

Если нужно вернуть целое и гарантировать целочисленность точки (друзья в целых координатах, точка встречи тоже), то \(m = \text{round}(S / n)\) не всегда оптимально для целых точек — но в условии ограничения не уточнены, поэтому дробный ответ корректен.
