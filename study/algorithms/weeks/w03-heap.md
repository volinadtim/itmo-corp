## 1. Двоичная куча (Binary heap)

### Определение

**Двоичная куча (пирамида)** — двоичное подвешенное дерево, для которого выполнены:

1. **Свойство кучи:** значение в любой вершине не больше значений её потомков (для *min-heap*) или не меньше (для *max-heap*).
2. **Форма дерева:** на i-м слое 2ⁱ вершин, кроме последнего. Последний слой заполняется **слева направо**.

> Источник: [neerc.ifmo.ru/wiki — Двоичная куча](https://neerc.ifmo.ru/wiki/index.php?title=Двоичная_куча)

### Хранение в массиве

Удобнее всего хранить кучу в массиве `a[0..n-1]`:

- `a[0]` — корень;
- потомки `a[i]`: `a[2i+1]` (левый) и `a[2i+2]` (правый);
- родитель `a[i]`: `a[(i-1)//2]`.

Высота кучи: **O(log n)**.

### Базовые процедуры

#### siftDown (просеивание вниз)

Используется, когда значение элемента **увеличилось** (в min-heap).

```
function siftDown(i):
    while 2*i + 1 < heapSize:
        left = 2*i + 1
        right = 2*i + 2
        j = left
        if right < heapSize and a[right] < a[left]:
            j = right
        if a[i] <= a[j]:
            break
        swap(a[i], a[j])
        i = j
```

**Время:** O(log n).

#### siftUp (просеивание вверх)

Используется, когда значение элемента **уменьшилось** (в min-heap).

```
function siftUp(i):
    while i > 0 and a[i] < a[(i-1)//2]:
        swap(a[i], a[(i-1)//2])
        i = (i-1)//2
```

**Время:** O(log n).

### Основные операции

| Операция | Псевдокод | Время |
|----------|-----------|-------|
| **Извлечение минимума** | `extractMin`: берём корень, ставим последний элемент на его место, `siftDown(0)` | O(log n) |
| **Вставка** | `insert(key)`: ставим в конец, `siftUp(heapSize-1)` | O(log n) |
| **Получение минимума** | `a[0]` | O(1) |

```
function extractMin():
    min = a[0]
    a[0] = a[heapSize - 1]
    heapSize--
    siftDown(0)
    return min

function insert(key):
    heapSize++
    a[heapSize - 1] = key
    siftUp(heapSize - 1)
```

### Построение кучи за O(n)

```
function buildHeap():
    for i = heapSize // 2 - 1 downto 0:
        siftDown(i)
```

**Почему O(n), а не O(n log n)?** Количество элементов на нижних уровнях экспоненциально больше, но они требуют меньше работы при siftDown. Сумма ряда: ∑_{h=0}^{⌊log₂n⌋} (n/2^{h+1}) · O(h) = O(n).

### Слияние двух куч

**Наивно** — O(n log n): извлекать элементы из одной и вставлять в другую.

**Через buildHeap** — O(n): скопировать все элементы одного массива в другой, затем вызвать `heapify()`.

## 2. Сортировка кучей (Heapsort)

> Источник: [neerc.ifmo.ru/wiki — Сортировка кучей](https://neerc.ifmo.ru/wiki/index.php?title=Сортировка_кучей)

**Характеристики:**

- Время: **O(n log n)** в худшем / среднем / лучшем случае.
- Память: **O(1)** дополнительной (in-place).
- **Неустойчивая.**

### Алгоритм

1. Строим **max-heap** из массива (buildHeap).
2. Меняем корень (`A[0]`) с последним элементом (`A[n-1]`): теперь максимум на своём месте.
3. Уменьшаем heapSize на 1 и восстанавливаем свойство кучи (`siftDown(0)`).
4. Повторяем шаги 2–3, пока куча не опустеет.

```
function heapSort(A):
    buildHeap(A)          // max-heap
    heapSize = A.size
    for i = 0 to n - 1:
        swap(A[0], A[n - 1 - i])
        heapSize--
        siftDown(A, 0, heapSize)
```

### Пример

Массив: `[3, 2, 4, 1, 5]`

| Шаг | Массив | Действие |
|-----|--------|----------|
| 0 | 5 3 4 1 2 | buildHeap (max-heap) |
| 1 | 2 3 4 1 **5** | swap(0,4); heapSize=4; siftDown |
| 2 | 1 3 2 **4 5** | swap(0,3); heapSize=3; siftDown |
| 3 | 2 1 **3 4 5** | swap(0,2); heapSize=2; siftDown |
| 4 | 1 **2 3 4 5** | swap(0,1); heapSize=1 → готово |

### JSort (модификация)

- Строим min-heap → почти упорядоченная левая часть.
- Строим "зеркальную" max-heap → почти упорядоченная правая часть.
- Затем **сортировка вставками** за O(n) на почти отсортированном массиве.
- Худший случай: O(n²).

## 3. Дополнительные темы

### priority queue (очередь с приоритетом)

Двоичная куча — частный случай приоритетной очереди. Поддерживает:
- `insert(key, priority)` — добавление;
- `extractMin()` / `extractMax()` — извлечение элемента с наименьшим/наибольшим приоритетом;
- `peek()` — просмотр без извлечения;
- опционально: `decreaseKey()` / `increaseKey()`.

### decrease_key

Уменьшение ключа элемента:
- Находим элемент, уменьшаем его значение;
- Вызываем `siftUp(i)` (для min-heap — элемент стал меньше, поднимается вверх).

Применение: алгоритм Дейкстры, алгоритм Прима.

### d-ичные кучи

В d-ичной куче каждый узел имеет до d потомков. Для массива с индексом i:
- потомки: `d·i + 1, …, d·i + d`
- родитель: `(i - 1) // d`

| Операция | 2-ичная куча | d-ичная куча |
|----------|-------------|--------------|
| siftDown | O(log₂ n) | O(d·log_d n) |
| siftUp | O(log₂ n) | O(log_d n) |
| insert | O(log₂ n) | O(log_d n) |
| extractMin | O(log₂ n) | O(d·log_d n) |
| buildHeap | O(n) | O(n) |

Выбор d: чем больше d, тем ниже дерево, но дороже siftDown (нужно сравнить d потомков). Для приоритетных очередей с частыми `decreaseKey` (куча Дейкстры) иногда используют d = 4 или d = 8.
