# Неделя 1. Время работы алгоритма. O-нотация

**Задачи:** 1.1–1.20

> Источник: [neerc.ifmo.ru/wiki — Алгоритмы и структуры данных](https://neerc.ifmo.ru/wiki/index.php?title=Алгоритмы_и_структуры_данных) (раздел «Амортизационный анализ»)

## Определения

- **O(g(n))** — верхняя оценка: функции f(n) ≤ c·g(n) при n ≥ n₀.
- **Ω(g(n))** — нижняя оценка: f(n) ≥ c·g(n) при n ≥ n₀.
- **Θ(g(n))** — точная оценка: f(n) = O(g(n)) и f(n) = Ω(g(n)).
- **Мастер-теорема:** T(n) = a·T(n/b) + nᶜ.

## Разбор

- 1.1–1.12 — доказательства по определению O/Ω/Θ.
- 1.13–1.19 — индукционные доказательства, дерево рекурсии, мастер-теорема.
- 1.20 — сравнение асимптотик двух алгоритмов.
