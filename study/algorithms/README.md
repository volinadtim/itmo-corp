# Алгоритмы и структуры данных (АиСД) — 1 семестр

Папка для обучения по предмету «Алгоритмы и структуры данных» (АиСД).
Соответствует блоку «Компьютерные науки» учебного плана КТ (1 семестр, 144 ч).

## Материал

**Источник:** [сборник ДЗ](materials/algo-sem1-homework.pdf) — АиСД, группы M3134–M3137,
версия от 25 декабря 2023 г. Сборник построен по неделям (12 тем).

## Референс по теории

В качестве основного теоретического источника используется
[neerc.ifmo.ru/wiki — Алгоритмы и структуры данных](https://neerc.ifmo.ru/wiki/index.php?title=Алгоритмы_и_структуры_данных).
Все конспекты сверяются с этим источником.

## Как устроена папка

```
study/algorithms/
├── README.md         ← вы здесь (карта курса)
├── .cursor/rules/    ← правила для агента (референсы и т.д.)
├── materials/        ← исходные материалы (PDF и др.)
├── weeks/            ← по одной заметке на неделю/тему
└── solutions/        ← решения задач (код + пояснения)
```

## План обучения

- Разбираем темы по неделям в порядке следования.
- Для каждой темы заполняем конспект в `weeks/`.
- Задачи (устная часть + код) решаем и складываем в `solutions/wXX/`.
- Оценка сложности/статус отмечается в конспекте темы.
