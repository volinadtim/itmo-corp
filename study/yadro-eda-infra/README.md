## О чём курс (по слайдам лекции 05.10)

Лекция «EDA-экосистема и управление данными»: как устроена вычислительная и data-инфраструктура, на которой проектируют микросхемы.

### Слайд 7 — Синтез и P&R: почему это «тяжёлые» задачи
- **Синтез**: RTL (Verilog/VHDL) → netlist из вентилей и триггеров. Logic synthesis (RTL → AND/OR/DFF), physical synthesis (с учётом площади, задержек, мощности). Инструменты: Synopsys Design Compiler, Cadence Genus.
- **P&R**: placement (размещение элементов на кристалле) и routing (прокладка соединений). Инструменты: Cadence Innovus, Synopsys ICC2.
- Сравнение с «лёгкими» задачами:

| Критерий | Синтез и P&R | «Лёгкие» задачи |
|---|---|---|
| Объём данных | миллионы вентилей | тысячи строк кода |
| Память | 256 ГБ – 2 ТБ на задачу | 1–16 ГБ |
| Время | часы – дни | минуты |
| Параллелизм | ограниченный | хорошо параллелится |
| Итеративность | многократные прогоны до сходимости | обычно один прогон |

- Причины «тяжести»: NP-сложные задачи (комбинаторная оптимизация); многомерность (timing, power, area, DRC, signal integrity одновременно); итеративность (после routing нарушения timing → возврат к placement); огромные объёмы (десятки млн вентилей, сотни км соединений).
- Внизу слайда — пайплайн **Схема RTL → Синтез → Netlist → Placement → Routing → GDSII** с пустыми полями `RAM:` / `Time:` у каждого этапа. На слайде подсвечены поля у «Синтез» — вероятно, интерактив/вопрос лектора: оценить потребление RAM и время на каждом этапе. **Заполнить, когда лектор назовёт цифры.**

### Слайд 8 — Intel Xeon vs AMD EPYC: что выбрать для EDA
| Критерий | Intel Xeon (Sapphire/Emerald Rapids) | AMD EPYC (Genoa, Genoa-X, Turin) |
|---|---|---|
| Ядра | до 60/сокет | до 192/сокет |
| 3D V-Cache | нет | да (Genoa-X: до 1.1 ГБ L3) |
| Производительность в EDA | высокая частота | высокая плотность ядер, кэш |
| Пример ускорения | — | 1.94× в Altair AcuSolve (2P EPYC 9684X vs 2P Xeon 8480+) |
| Рекомендация | single-thread задачи | multi-thread задачи, P&R |
