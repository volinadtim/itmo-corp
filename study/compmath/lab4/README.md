## Требования (гл. 34)

- Все три варианта сразу: левые, правые, средние прямоугольники; параметры пользователь задаёт один раз.
- ОДЗ, условия существования определённого интеграла.
- Устранимый разрыв 1-го рода: устранить (сообщить пользователю способ), продумать разрыв на границе интервала.
- Погрешность квадратурной формулы (rᵢ и R), сравнение с аналитическим значением.
- Сравнение по шагу / числу разбиений.
