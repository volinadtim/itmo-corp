## Требования (гл. 35)

- Несколько ОДУ на выбор; начальные условия и длину интервала задаёт пользователь.
- График: начальное условие, численное решение, аналитическое решение.
- Аппроксимация на графике — методом из ЛР1 (один раз, без удаления точек). *В методичке написано «из ЛР4», по смыслу — ЛР1; уточнить.*
- Анализ: устойчивость, накопление ошибки, разные начальные условия для одного уравнения.
