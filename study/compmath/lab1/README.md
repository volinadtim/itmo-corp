## Требования (гл. 31, §31.2)

- Аппроксимация **линейной комбинацией сигмоид**, построенной по входным точкам (не одна фиксированная сигмоида).
- Метод применяется дважды: по полному набору и после удаления точки с наибольшим квадратом отклонения.
- График: исходные точки, обе аппроксимации, выброшенная точка выделена; желательно исходная функция.
- Вывести полученные коэффициенты.
- Свои наборы точек из известной функции, желательно несколько и с шумом.
