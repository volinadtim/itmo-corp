## Требования (гл. 32)

- Матрицы до 20×20; обязательно проверить на 20×20 и пример с 5–6 неизвестными в отчёте.
- Ввод: с клавиатуры, из файла, генерация (лучше: загадать x, посчитать B, сравнить).
- Обработка ошибок ввода как можно раньше, и для файла тоже.
- Вывод (прямой метод): определитель, треугольная матрица (с преобразованным B), столбец неизвестных, столбец невязок.
- Анализ скорости: сложность по блок-схеме + замеры.
- В выводах сравнить с другим прямым методом и прямые с итерационными.
- Первые тесты: все A = 0; все A = 1; матрица, чей определитель проверяется по Крамеру.
