# itmo-corp

Рабочее пространство для учёбы в Университете ИТМО: восстановление, сессии, предметы, документы.

## Статус

| Направление | Статус |
|---|---|
| Восстановление (apply-itmo) | в работе — подача летом 2026 |
| Подготовка к предметам (study) | в работе — КТ, академ. разница 1–2 курс |
| Общие материалы (shared) | черновик |

## Структура

```
itmo-corp/
├── README.md           ← вы здесь
├── .env.example        ← шаблон credentials для my.itmo.ru
├── apply-itmo/         ← восстановление, финансы, документы, план
├── integrations/my-itmo/  ← доступ к my.itmo.ru (MCP + scripts)
├── study/              ← учебный план КТ, ресурсы для академ. разницы
└── shared/             ← общий контекст: профиль, ссылки, календарь
```
