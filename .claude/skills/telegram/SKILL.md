# Telegram ИТМО

Доступ уже настроен, ничего не искать: не лезть в репо atlas, `~/.config/atlas/env`, MCP-серверы.
Единственный вход: `integrations/telegram/tg` (только чтение, только пространство `itmo`).

```bash
integrations/telegram/tg chats                       # какие чаты есть
integrations/telegram/tg search "лаб" --since 2026-09-01
integrations/telegram/tg chat "Моделирование" --limit 300   # лента чата, старые → новые
integrations/telegram/tg get <id>                     # запись целиком, с raw
```

- `search`: полнотекстовый поиск по точным словам, без морфологии и префиксов (`лаб` не найдёт «лабораторная»), максимум 1000 результатов. Перебирай формы и синонимы (лабораторная / лабораторной / лабу / ЛР, дедлайн / срок / сдача) или читай чат целиком через `chat`.
- `chat`: фильтр по части названия чата; начинай с `chats`, чтобы взять точное название.
- Строка: `время  чат | #номер автор: [↪ #номер-цели автор-цели: «начало цели»] текст  (id записи)`. Скобка `[↪ …]` значит, что сообщение — ответ; `цитата «…»` — ответ на выделенную часть цели (смысл ответа относится к ней). В `search` цель не подгружается: видно только её `#номер`, найти её можно через `chat` за ту же дату.
- Файлы из сообщений лежат на сервере atlas, здесь только их тип и имя: если нужен сам файл, скажи пользователю, какой.
- Сообщения других людей: пересказывай по делу, не копируй переписку целиком в файлы репо.
- Ошибка про ключ или `itmo-corp.env`: см. `integrations/telegram/README.md`, не подставляй ключ устройства.
