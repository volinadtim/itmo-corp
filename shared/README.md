# shared — общий контекст (черновик)

> Полноценная точка входа будет здесь. Пока — минимальный каркас.

## Назначение

Единое место для информации, которая нужна **всем** подпроектам itmo-corp:

- профиль студента
- академический календарь ИТМО
- ссылки на my.itmo.ru, ISU, Moodle
- статус текущих процессов

## Планируемые файлы

| Файл | Содержание |
|---|---|
| `profile.yaml` | ИСУ, направление, ОП, контакты |
| `calendar.md` | Ключевые даты семестра, сессии, ППА |
| `links.md` | Все полезные URL |
| `status.md` | Текущий статус: восстановление, предметы, финансы |

## Связь с подпроектами

```
shared/profile.yaml
    ├── apply-itmo/   ← восстановление
    └── study/        ← подготовка к предметам
```
